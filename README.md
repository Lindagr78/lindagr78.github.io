```text
/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── img/
        └── favicon.svg
```

## Publicar no GitHub Pages

Envie todos os arquivos deste pacote para o repositório:

`danmoreiradev.github.io`

Mantendo exatamente a estrutura de pastas.

Depois acesse:

**Settings → Pages**

E configure:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

O site será publicado em:

`https://danmoreiradev.github.io`
